# Prime Mesh R2Q - H-Exc T_J Grid Extraction Audit v1

**Status:** PASS

## Extracted Rule

Script inspection gives the proof-facing rule:

```text
SR11 first builds h-samples with geometric_h_values(max_h):
{1,2,3,4,5,8,10,16,32,64,128} plus round(geomspace(1,max_h,36)) plus max_h.

Route A then defines, for a selected candidate J=(block_id,y,h):
T_J = {y} union {y+r : r is an available SR11 h-sample for (block_id,y), r <= h} union {y+h}.
```

The h-grid rule is independent of Lambda events. Candidate selection may be empirical, but the sampled offsets are not generated by inspecting prime-shock events.

## Interpretation

The clean replacement theorem should not define `T_J` as the full integer grid. It should define `T_J` as the Route-A SR11 subgrid above. A simpler `{0} union geometric_h_values(h)` rule matches most rows, but not all rows, including one post-P0 row.
